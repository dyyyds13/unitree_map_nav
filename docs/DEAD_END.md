# 死胡同响应、倒退与管道高度

2026-11-15。官方场景与MPC普通步态不改；不开启视频、图片、物理或原始传感器录制。真实Go2未知设备模板与实物速度默认不变，未运行实物运动。

## 改动

- DWA的固定0.08m/s倒退上限改为独立`max_reverse_vx`。无配置仿真默认0.25，可用`--max-reverse-speed .25`覆盖；配置文件有值时保留，命令行优先。真实设备默认0.08。
- 仅ordered路线显式reverse段启用较高倒退上限；普通检查点/SE(2)恢复仍最多0.08、缓冲区退出0.05、标记窄口最多0.15。完整后方车身、地面、净空、水面及制动尾段检查保留。保持普通行走原有速度采样端点，以免倒退调整扰动上坡控制。
- 已知固定路线的死胡同前墙在接近检查点时连续3帧确认，10Hz下约0.2秒；它依然使用明确路线先验，不是通用的未知地图死胡同拓扑分类器。
- 检查点允许0.25m的安全到达区域（此前0.15m），仍要求确认前墙、正确朝向、停稳保持1秒。停稳结合约0.4秒的平均关节/IMU速度与估计位移窗口；不能以定时器代替观测。
- 实际日志发现，原先定位在到达边界抖动约1～3毫米，导致1秒计时不断清零。保持开始后容许额外0.02m迟滞，course和controller共用同一判据；超过区域或明显移动仍重置。并非缩短所有安全等待。
