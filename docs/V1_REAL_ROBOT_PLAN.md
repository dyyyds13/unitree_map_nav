# 初代实物方案（修订版）

后续用户已追加MuJoCo仿真与开源MPC要求，现已实现；最新运行入口、验证及边界见MUJOCO.md。本文件保留最初实物部分范围。

2026-11-15，Asia/Shanghai。

## 已确认范围

用户选择调用 Go2 自带行走接口；型号、传感器和机载计算机先按未知处理。
初代无需训练、无需RL策略、不强制ROS 2；实现实物自主系统的算法与适配接口。
后续再考虑学习式方法和比赛ONNX提交。厂家内部控制器采用什么算法不由本项目决定。

## 本次落地结构

1. 安装项目交接工具，官方资源保持可校验。
2. 统一真实传感器观测和回放格式，隔离硬件驱动。
3. 提供平面ICP/关键帧位姿图与可选KISS-ICP后端。
4. 维护地面支持和净空地图，接通A*、DWA、探索、回退和重规划。
5. 使用无需训练的黑白足球圆弧/纹理检测、几何定位、跟踪与去重。
6. 任务状态机产生开始/目标/本地终点事件；SDK接收速度指令并提供超时停车。
7. 用合成传感器、回放与模拟SDK做软件验收；实物验收在型号和驱动明确后进行。

## 优先复用的开源能力

- Unitree SDK2 Python：原生状态、相机、运动服务。
- KISS-ICP：可配置的三维雷达里程计。
- OpenCV：边缘、轮廓、相机几何、ArUco。
- NumPy/SciPy：数值计算、最近邻、位姿图优化、数据关联。
- A*、DWA、ICP等算法按本项目坐标、地面支持和接口独立实现；不是将PythonRobotics整套作为可直接部署包。

## 验收界线

完成标准是“软件模块可运行、接口可接实物、测试结果可复查”。
不将合成场景通过率当作比赛成绩或实机成功率。
正式报位坐标、终点协议、地形通过能力、硬件SDK权限和真实检测精度仍需现场验证。
具体执行结果以VALIDATION.md和输出日志为准。
