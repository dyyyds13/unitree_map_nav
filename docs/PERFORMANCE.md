# 仿真性能与S弯分叉口

2026-11-15。普通运行默认不录屏，不输出视频、图片/地图快照、物理NPZ、原始传感器记录，也不导出约64MB的运行场景副本。保留小型配置/场景来源/路线、终端诊断、trajectory和summary，以便定位停车原因；旧输出不删除。

```bash
.venv/bin/go2-rescue mujoco --viewer --realtime --task-fixture --seconds 600 --output "output/run-$(date +%Y%m%d-%H%M%S)"
```

需要诊断归档时分别显式添加：`--video`视频；`--record`原始RGB/雷达；`--save-physics`采样物理状态及本地场景；`--snapshots`地图/图片快照及本地场景。`--record`不再隐含视频；没有任何默认录制。相机仍为导航生成10Hz观测，关闭录屏不能关闭导航所需传感器。

物理步进、凸MPC、定位/建图/规划和OpenCV感知使用CPU。相机/窗口通过OpenGL渲染，启动日志和summary显示实际GL_RENDERER；本机实测NVIDIA GeForce RTX3060 Laptop GPU，不能把GPU占用率解释为MPC在CUDA上求解。

此前窗口只在10Hz录像循环sync，并重复渲染一次前视相机、编码960×480视频，还把所有带图像Frame留在内存。现在窗口独立同步（默认上限60Hz，`--viewer-fps`可调1～120），录像按需创建并复用最近相机图；Frame改为计数，耗时统计使用有界队列。小型矩阵BLAS线程限制为1，退出恢复；稀疏地面列的下包络中位数按列长度批量计算，保留原数值语义。

用户两份fast日志均停在S_curve第4检查点：`ordered_align_checkpoint`、全零速度，未跌倒，最后由用户关闭窗口。提速后到原点时朝向未对齐，转动扫描被墙面拒绝，小目标区域也找不到恢复姿态。路线先验把该转向位置提前25厘米到转向区，不修改官方地图。检查转向的1.5秒范围不再超过所需最终朝向。返回后的标记窄口恢复2厘米额外余量；完整物理车身、地面、净空、水面及制动检查不变。

实测：

- `smooth-viewer-02`：实际桌面窗口8.0仿真秒/8.010墙钟秒，434次sync（约54.2次/秒），RTX3060渲染、四类录制全关闭、未跌倒。这是脚本MPC短测，不是自主整圈或稳定60fps保证。
- `smooth-junction-01`：原起点Autonomy120仿真秒/106.591墙钟秒，通过上坡/下坡/S弯，死胡同已进退；0诊断障碍接触/入水/越界、无跌倒，到时限结束在死胡同返回后的转向点。无视频/物理/快照。该轮只含早期性能与路线改动，非最终全部补丁。
- `smooth-junction-02`：中间版本验证S弯、死胡同及返回分叉口的两个窄口后，继续进入碎石区；随后人为中断做最终窗口复验。不是任务完成。

- `smooth-junction-final`：最终代码实际桌面窗口，从原起点155仿真秒/167.889墙钟秒，5067次sync（平均30.18次/秒；不是实际绘制FPS测量）。完成L1上坡、下坡、S弯、死胡同进退，145.3/148.4秒依次穿过返回分叉口两个窄口，151.7秒达到碎石区下一检查点；到时限结束在rubble waypoint3。诊断0障碍接触/入水/越界、未跌倒；full_course_pass=false。GL_RENDERER=RTX3060，四类录制全False；没有视频/图片/地图/物理/场景二进制，全部小型诊断文件共1240425字节（约1.24MB）。导航P95约112.6毫秒，复杂区域仍会超出单个100毫秒传感器周期，不能保证全程60fps。

全量99项测试通过（42.06秒），pip check、compileall、官方SHA256校验通过。未测试实物、不同噪声种子整圈或2号管道自主穿越。
